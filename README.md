# AI-from-Scratch
## Init
My very own implementation of a Bag-of-Words AI Model built using python that uses no third-party dependencies like tensorflow, numpy or scikit learn, basically everything that is required from model training to model execution, implementing from scratch.

## Dataset
The dataset I used for this is [UCI Machine Learning Repository - Sentiment Labelled Sentences](https://archive.ics.uci.edu/dataset/331/sentiment+labelled+sentences) I did not decide which file to use at the time writing.
The plan is to create a model and train it individual domain of review (Movies, Products and Restaurants) but also optimise this model to handle all these domains in one.
